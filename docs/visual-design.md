# 视觉设计规范

东软电动汽车充电桩应用管理平台 — Qt 用户端、Qt 管理端、Web 数据大屏的统一视觉语言。
所有界面实现以本文档为准；新增组件或颜色前先更新本文档。

## 1. 设计目标

- 三个端看起来像"同一个产品"：同一套色板、同一套语义色、同一套组件规则。
- 管理端：宽屏 PC 后台风格，信息密度高，以表格、图表为主。
- 用户端：模拟手机端体验，竖屏、大点击区域、卡片式列表。
- Web 大屏：深色科技风，远观可读，数字突出。

## 2. 色彩体系

### 2.1 品牌主色

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 Primary | `#00A870` | 充电绿。导航选中态、主按钮、链接、强调数字 |
| 主色-按下 | `#00875C` | 主按钮按下/悬停 |
| 主色-浅底 | `#E3F6EF` | 选中行底、标签底、主色浅背景 |

### 2.2 中性色

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面背景 | `#F5F6F7` | 管理端/用户端页面底 |
| 卡片背景 | `#FFFFFF` | 卡片、表格、对话框 |
| 边框 | `#E0E3E6` | 卡片描边、分隔线、表格线 |
| 文本-主 | `#1F2329` | 标题、正文 |
| 文本-次 | `#6B7280` | 辅助说明、占位符、次级信息 |

### 2.3 语义色（与管理端实现一致，协议状态的固定映射）

| 语义 | 色值 | 对应状态 |
|---|---|---|
| 成功 / 空闲 / 正常 | `#2E7D32` | 电桩 `idle`、用户 `normal`、操作成功 |
| 信息 / 在用 | `#1565C0` | 电桩 `in_use`、进行中状态 |
| 错误 / 故障 / 冻结 | `#C62828` | 电桩 `fault`、用户 `frozen`、操作失败 |
| 警告 | `#ED6C02` | 余额不足、占比过高等提醒，非错误 |

状态一律"着色文字"或"着色标签"呈现，禁止只靠颜色以外不加文字（表格状态列必须有汉字）。

### 2.4 图表配色序列

QChart 与 ECharts 共用同一序列，多系列时按序取色：

`#00A870`、`#1565C0`、`#F59E0B`、`#7C3AED`、`#EC4899`、`#14B8A6`

单系列折线/柱状一律用主色 `#00A870`。坐标轴文字用 `#6B7280`，网格线用 `#E0E3E6`。

### 2.5 Web 大屏专用

| 角色 | 色值 |
|---|---|
| 大屏背景 | `#0B1E33` |
| 面板背景 | `#122A45` |
| 数字高亮 | `#00E396` |
| 大屏正文 | `#D7E3F2` |

## 3. 字体与字号

字体族：`Noto Sans CJK SC`、`Microsoft YaHei`、`PingFang SC`，按平台回退；禁止衬线体。

| 场景 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 18px | Bold |
| 指标卡数字 | 26px | Bold |
| 卡片标题 / 表头 | 14px | Medium(Bold) |
| 正文 / 表格内容 | 13~14px | Regular |
| 辅助说明 | 12px | Regular，配 `文本-次` 色 |

## 4. 布局规范

### 4.1 管理端（宽屏 PC）

- 窗口默认 `1280×800`，最小 `1120×700`。
- 左侧导航：宽 `200px`，深色底 `#1F2937`，文字 `#D7DDE5`；选中项：左侧 `4px` 主色指示条 + 主色浅底文字高亮。
- 内容区：页面背景 `#F5F6F7`，内容与边缘留白 `16px`，卡片间距 `16px`。
- 指标卡：白底、圆角 `8px`、边框 `#E0E3E6`、内边距 `16px`，横向均分一行最多 4 张。
- 表格：表头灰底 `#F0F2F4`、行高 `36px`、斑马纹 `#FAFBFC`、不可编辑、整行选择、单列选中。
- 页面切换时自动刷新数据，并提供「刷新」按钮。

### 4.2 用户端（模拟手机）

- 窗口固定竖屏 `390×844`（不允许调整大小），模拟手机比例。
- 底部 Tab 导航：不超过 4 个（建议：首页/找站、充电、订单、我的）。
- 列表项即卡片：白底圆角 `8px`，间距 `12px`，点击区整卡可点。
- 主要操作按钮：全宽、高 `44px`、主色填充、圆角 `8px`。
- 金额、距离、功率等关键数字用主色或加粗突出。

### 4.3 Web 大屏

- 16:9，按 `1920×1080` 设计、等比缩放。
- 深色底 + 面板式布局，面板间距 `16px`；核心数字字号 ≥ 36px。

## 5. 组件规范

| 组件 | 规则 |
|---|---|
| 主按钮 | 主色填充白字，圆角 `6px`，高 `32px`（用户端 `44px`）；按下用 `主色-按下` |
| 次按钮 | 白底、`#E0E3E6` 边框、`文本-主` 字 |
| 危险操作按钮 | 不使用红色填充；与次按钮同样式，点击后弹确认框 |
| 确认对话框 | 仅用于不可逆或影响他人的操作（重启电桩、冻结/解冻用户）；文案格式「确定要<操作><对象> 吗？」 |
| 结果反馈 | 成功/失败均用统一弹窗样式：标题为操作名，正文一句话说明结果；失败正文优先显示服务端 `msg` |
| 输入框 | 高 `32px`，边框 `#E0E3E6`，聚焦边框变主色；非法输入在点「确定」后统一弹窗提示，不做行内红字 |
| 状态标签 | 表格内用着色文字（语义色），弹窗/详情内可用圆角色块标签 |
| 异步等待 | 请求发出后按钮立即禁用，响应到达后恢复；不做转圈动画 |
| 空状态 | 表格无数据时保留表头，不弹窗；列表为空显示一行 `文本-次` 色提示 |

## 6. 实现约定（Qt）

- 样式集中写在 QSS 文件，经 `qrc` 加载：`admin/resources/style.qss`、`client/resources/style.qss`，两端内容保持同步（仅尺寸类规则可按端调整）。
- 代码中禁止出现散落色值字面量；颜色只允许取自本文档色板，语义色映射集中在 `ui/uienums.h`（管理端）/ 用户端对应文件。
- 本文件与 `docs/protocol.md` 平级，改动须通知另一端的负责人。
