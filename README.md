# 东软电动汽车充电桩应用管理平台

小学期实训项目（第 13 组）。面向电动汽车充电运营场景，构建覆盖「用户端 — 服务端 — 数据端」全链条的综合管理平台，贯通需求理解、整体设计、详细设计、开发、测试、发布的完整软件流程。

## 系统架构

系统由五个模块构成，项目实施期间不再增加新模块：

```
┌──────────────┐                  ┌──────────────┐
│  Qt 用户端    │                  │  Qt 管理端    │
│ (车主 App)    │                  │ (运营后台)    │
└──────┬───────┘                  └──────┬───────┘
       │  TCP Socket / JSON              │  TCP Socket / JSON
       └──────────────┬─────────────────┘
                      ▼
              ┌──────────────┐         ┌──────────────┐
              │ Socket 服务端 │◄────────│  Web 数据大屏 │
              │  (多线程)     │  JSON   │  (ECharts)   │
              └──────┬───────┘         └──────────────┘
                     │ SQL
                     ▼
              ┌──────────────┐
              │ SQLite 数据库 │
              └──────────────┘
```

两个 Qt 端都是 Socket 服务端的客户端，不直接访问数据库，彼此也不直接通信；所有业务逻辑与数据一致性由服务端收口。

## 功能概览

| 模块 | 主要功能 |
|---|---|
| Qt 用户端 | 手机号免密登录/自动注册、资料与模拟充值、附近充电站查询（腾讯地图 API 模拟定位）、一键导航（QWebEngineView）、预约—充电—计费—结算全流程、历史订单 |
| Qt 管理端 | 管理员登录、营收指标（今日/本月/总营收）、7 日/30 日营收趋势（QChart）、电桩状态与列表、远程重启模拟、站点列表与新增站点、用户查询与冻结/解冻 |
| Socket 服务端 | 五张核心表（users / admins / stations / piles / orders）访问封装、JSON 消息分发、充电状态顺序控制（预约→开始→停止→结算→释放） |
| Web 数据大屏 | 营收、订单数、充电量、电桩状态、站点列表的可视化展示，页面加载读取服务端 JSON，支持手动刷新 |

## 技术栈与开发环境

- 运行环境：VMware 17 虚拟机，Ubuntu 22.04+
- 开发工具：Qt Creator 6.2+
- 语言与框架：C++，Qt（QChart、QWebEngineView），SQLite，Socket 多线程编程
- 大屏：Web 页面 + ECharts

## 构建与运行

各模块为独立的 Qt Creator 工程，进入对应目录用 Qt Creator 打开 `.pro` 文件构建即可。启动顺序：先启动 `server`（默认监听 8888 端口），再启动 `client` / `admin` / `web`。详细启动步骤待项目收尾时补充完整。
